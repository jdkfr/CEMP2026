# CEMP2026
We present CEMP2026, a provably correct 3:1 compression scheme using Latin squares. It employs modular arithmetic and a dual-mode encoding strategy to guarantee bijectivity. The scheme maps 3 input bits $(a,b,c)$ and a 3-bit state $s$ to a single transmitted bit $x$ and new state $s'$, achieving lossless compression with 100\% correct decoding. Bijectivity is constructively proven, and the algorithm requires only table lookups and simple arithmetic.
